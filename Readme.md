Project Saarthi is an intelligent system designed to assist in handling emergency calls to the 112 service. It automates information gathering from callers, uses AI to determine the necessity of police, ambulance, or other emergency services, and triages the response accordingly. The system can decide whether to escalate to a human operator and alerts the appropriate emergency services with the caller's location. Additionally, it incorporates an emotion aware AI to tailor its responses for a more empathetic interaction.

*   Automated information gathering from emergency callers.
*   AI-driven assessment of required emergency services (police, ambulance, etc.).
*   Intelligent triage to determine human operator escalation.
*   Automated alerts to relevant emergency services with location data.
